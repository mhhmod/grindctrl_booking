The employee sees a caller number, a permitted associated name, Icons Club tier, optional email and individual-call history with each call’s own human note. Agent D records a new note for DEMO-1012. A later DEMO-1015 call handled by Agent E reads that original note with its original source, author and timestamp; it does not become a future-call or customer-global note.

All profiles, membership, calls, dates and notes are synthetic and labeled. Concrete’s actual UI, sources, note storage, role grants and retention were not inspected. Native note-save behavior and any integration requirement remain to validate in authorized configuration review and pilot calls. No live connector, automatic Zoho synchronization, AI-generated note, call recording, measured savings or completed GRINDCTRL deployment is claimed.

Both movies fully decoded and played unmuted through the ending. Audio drift checks at eleven checkpoints found zero best-lag drift; 84 encoded frames were checked against HTML states. Seven offline scenario groups and 133 audio/visual seek destinations were checked. Precise methods and limitations are in QA; no human full listen-through or participant study is claimed.

HTML/MP4 are the synchronized masters. PPTX/PDF are twelve-page static references: eight main scenes plus complementary note-entry/exception states. PowerPoint contains editable native shapes/text and the original MP3; Microsoft PowerPoint audiovisual behavior is unverified. Install the bundled OFL fonts before editing.
