# Editable PowerPoint and reference PDF

Both PowerPoints have **seven main chapters plus an editable record-choice appendix**. Text, UI surfaces, separators, states and diagrams are native editable elements. Logos/icons are raster artwork. Manrope and IBM Plex Sans Arabic fonts are included under `source/assets`; install them for native fidelity. HTML, video and PDFs carry their own rendered font appearance.

The unchanged original MP3 is embedded in slide 1. A small microphone in its footer is the media object. Native XML includes timed fade entrances, automatic advances for the first six chapters, and an audio node configured to span the seven main slides. The final chapter holds; the appendix can be opened separately. Timing offsets come from the actual narration sheet.

Microsoft PowerPoint playback is **not available for testing here**. The package has been opened and rendered in LibreOffice, and its text, bounds, timing targets and original-audio hash have been checked. That establishes file/layout integrity; it does not certify Microsoft PowerPoint's media behavior or cross-slide narration continuity. PowerPoint for Web, preview services and alternate office apps may ignore timing/media nodes. HTML/MP4 are the verified synchronized experiences.

Native effects simplify the browser's temporary focus outlines and the shared-number branch. The latter is an appendix, preventing layered chooser artwork from obscuring the main static context slide. Speaker notes retain exact cue references and limitations. Native editing or manual slide navigation can break narration alignment; use the HTML for pause/seek/replay and the MP4 for a fixed narrated playback.

Both PDFs contain the seven complete static scenes plus the shared-number appendix. They communicate the change without animation. They are visual references, not narrated documents.
