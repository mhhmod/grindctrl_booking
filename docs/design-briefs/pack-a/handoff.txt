3. Components
Existing (Mantine 9)
Card
Every surface that groups content. 20px radius, 1px border, card fill. 24px padding on desktop, 16px on phone.
Button
Primary (charcoal fill, cream text; reversed in dark), outline, quiet text button. 44px high, pill radius. Loading shows a spinner and aria-busy. Disabled uses muted fill and muted text.
TextInput
Store address, developer email, storefront password, note. 48px high, 12px radius. Address and email stay left-to-right in Arabic.
Radio.Card
Platform list rows (A2) and the two access choices in We install it for you. 48px minimum height, the selected row has a muted fill or a charcoal border.
Badge
Beta, Detected, and the status pill (Badge with a leading icon). Pill radius. Status pill: 28px high, 26px on phone inside product cards.
Alert
Address unreachable, already connected, disconnect confirmation, EasyOrders error, the updated code note on a product card. 12px radius, soft status fill, icon plus text.
Code + Copy
Code box with a Copy code button that turns to Copied for 2 seconds. Code is always left-to-right.
Switch row
Try-On and Store Chat switches inside the product cards. 48 by 28 track, the word On or Off beside it.
Numbered step list
The three steps (Your store, Paste one code, Check it's live). Marker 28px: green tick when done, charcoal number when current, outlined grey number when to do.
Skeleton
A1.3 checking and A6.4 Run check now. Muted bars, no shimmer needed; respect reduced motion if one is added.
Drawer (bottom)
Phone platform picker (A2). Bottom sheet over a 45% scrim, 20px top radius, grabber, Done button.
New
Product card
Anatomy: icon tile (44px, 32px on phone), name, status pill, switch on the first row; one sentence, the looks line (Try-On only) and See it on your store on full-width rows below. States: off (no pill, grey sentence), on with any of the five pill kinds, on with an updated code note. Hover: none on the card. Focus: on the switch and the link only. Disabled: switch greyed while a change is saving. Loading: pill shows Waiting for data until the first check. Error: sentence turns to the can't-see wording and the pill reads Not working. Spacing: 8px between header and body, 6px between body lines, body indented 56px on desktop to sit under the name.
Store check row
Anatomy: status pill (fixed 160px column), row title in bold, one sentence, one fix button (fixed about 190px column). On phone the three parts stack and the button is full width. States: Not working (the first such row gets the primary button), Needs attention (outline button). Hover and focus on the button only. Loading: the whole list is replaced by skeleton rows during Run check now. Spacing: 16px vertical padding, 24px side padding (16px on phone), 1px divider between rows.
Optional row
Lives in the quiet group More you can add, which has a border and no fill. Anatomy: title with an optional Beta badge, one sentence, one outline button that may carry a platform logo. No status pill.
Working well line
A healthy row collapsed to one line: green tick, name in bold, short grey sentence. 44px minimum height. The Code on your store line ends with the quiet text link Install steps.
Detected platform chip
A pill with the platform logo in its own colours, the platform name and an optional Beta badge, inside a muted box with the sentence We found a ... store and a Change link. Variants: detected, any website (globe, no error tone). 36px high chip, 44px link target.
Path chips
The menu path inside a platform. Each chip is a 28px muted pill. The arrow is glued to the chip that follows it so a line never ends with an arrow. Arrows mirror in Arabic. Platform menu names stay in the language the platform shows them in.
Short code box
Shopify only. Fixed height of about five lines (124px), fade over the last two lines, a Show full code text link under it that expands the box. Copy code always copies the full code.
Secondary options row
Three quiet text buttons under step 2 (Use Google Tag Manager, Send to my developer, We install it for you). One panel open at a time, inline, 12px radius. Google Tag Manager is hidden for Shopify and WooCommerce.
Request tracker
Requested, In progress, Live. Same markers as the step list at 24px, joined by a short line.
Live check block
Step 3 body. Waiting: a static dot in a muted circle (pulse allowed when motion is allowed), heading, helper, Open my store. Found: green tick and Continue. Not found: three causes with one-line fixes, Check again, We install it for you.
4. Interactions
A1 address field
Accepts anything: https, www, paths, bare Shopify names. Detection starts 600 ms after typing stops or on blur. Checking shows for 1 to 5 seconds, then the chip appears in place without moving the Continue button. Continue is disabled while empty or checking.
A2 picker
Opens from Change. Desktop: an inline panel inside the same card, never a modal. Phone: a bottom sheet. Picking a row applies at once; Done only closes the sheet.
A3 copy
Copy code turns to Copied for 2 seconds, then back. Show full code expands the Shopify box in place.
A3 secondary options
Each text button opens its panel inline under the row and closes the other two. Send shows the sent line in place of the form. The install request shows the tracker in place of the form and stays until Live.
A4 live check
The screen checks by itself every 5 seconds while it is open. Found moves to the success state. After 5 minutes it switches to We can't see your code yet. The storefront password is sent once for the check and never stored.
A5 switches
Turning a switch on shows the status pill at once as Waiting for data, then the real status after the first check, and reveals See it on your store, which opens the store in a new tab. Once any switch is on, the heading changes from Turn on what you want to On your store. Nothing shows to shoppers while both are off.
A6 Store check
Run check now disables the button, shows Checking and replaces the rows with skeletons for 5 to 20 seconds. The check time at the top is the only time shown. Rows are ordered Not working, then Needs attention; optional items sit in More you can add; healthy items collapse under Working well. Install steps expands the same collapsed steps as the just-connected state.
A6 Today card
Shows one status per product and View store check, which opens Your store. On phone, Your store also opens from the menu; the bottom bar is unchanged and highlights nothing on this page.
A7 emails
Sent only when something turns Not working, at most one per problem, with one follow-up when it works again. The button deep-links to the matching row.
A8 Connect EasyOrders
Connect opens EasyOrders in a new tab and the card shows Finish in the EasyOrders tab. I've approved it rechecks at once. Disconnect asks inline inside the card, never in a modal.
Arabic
Layout uses logical start and end, so everything mirrors. Arrows and chevrons mirror; logos, code, addresses, emails and pairing codes stay left-to-right. Western digits are used in both languages.
Motion and focus
With reduced motion the waiting dot and skeletons are static. Every control has a visible focus ring (3px, ring colour at 50%). Touch targets are at least 44px.
5. Departures from the brief
Own page
Install and Store check moved out of Store Chat into a page called Your store, after Store Chat in the sidebar. Asked for in review.
Two-part journey
Connect your store with one code, then turn on Try-On and Store Chat with separate switches. The A1 title and subtitle changed to match. Asked for in review.
One card per product
The success screen and Store check are the same page in two states. Each product card carries its switch, status and sentence. There is no single overall status. Asked for in review.
Store check grouping
What to fix, More you can add, Working well. Check time shown once. No Your code version row; a feature that needs newer code says so on its own card. Asked for in review.
Fifth status word
The brief has four status words. In preview is added as a neutral pill for the preview variant, so the card never claims Working well while shoppers can't see it.
WooCommerce wording
WooCommerce says Add the plugin and One plugin runs everything, and has its own detected state A1.4b. Asked for in review.
Google Tag Manager
Offered only where a pasted code works: not on Shopify or WooCommerce. Asked for in review.
A5 buttons
See it on your store sits on each product card once it is on. Try-On settings is not on this page; it stays under Try-On in the sidebar.
A8.1
The not-connected Connect EasyOrders card is shown on the A3 EasyOrders board, below the steps, as the brief places it.
Dark mode scope
Dark boards are made for A1, A2, A5 and A6 in English. Arabic dark uses the same tokens and was not drawn.
Dark sidebar
The selected sidebar item uses the border colour as its fill in dark mode, because the muted surface and the shell colour are almost the same there.
Logos in dark
Logos are never recoloured, so the black Squarespace mark is low contrast on dark surfaces. A light tile behind logos in dark mode would fix it.
Placeholders
The website code, the Shopify code, the pairing code, the verify tag, lulusfashion.com, dev@lulusfashion.com, alerts@grindctrl.cloud and all [TBC] steps are placeholders until the real ones are supplied.
Arabic terms to confirm
Try-On is القياس الافتراضي, Store Chat is محادثة المتجر, a look is إطلالة, a pill is شارة. The EasyOrders and WordPress menu names in Arabic are best guesses.
2. Every string, English and Arabic
Keyed by the screen and state where the string first appears. Text in single braces is a value filled in at run time. Brand names, addresses, codes and platform names are not translated.
