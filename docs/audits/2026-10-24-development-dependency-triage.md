# Development dependency triage for PR 75

Baseline reviewed: `209340229572c36a631a352f4244adbd29c80ee4`. `npm audit --json` reported **13 affected package findings: 5 moderate, 6 high, 2 critical**. All affected lockfile nodes were marked `dev: true`; `npm audit --omit=dev --audit-level=moderate` reported zero. That is inventory evidence, not proof that a build tool cannot affect production artifacts. This triage does not declare the critical findings harmless or accepted.

The dependency tree was inspected with `npm ls ... --all`; checked-in workflows invoke `vitest run` and a credential-free candidate build. The Next app runs through Next.js, not Vite. No application import of these vulnerable tool APIs was found in app/lib/components/scripts; `shadcn/tailwind.css` is a build stylesheet import. This is bounded repository inspection, not an exploit demonstration or inspection of every developer machine.

## Executed checks and remaining gate

Only compatible lockfile updates were requested for body-parser, Hono, ip-address, Undici, Vite and Zod. No package.json major range changed. Unrelated SWC platform/libc metadata was preserved. `npm ci --ignore-scripts` installs the reviewed lockfile locally; full CI uses its existing locked install and release checks.

Post-update `npm audit --json` reports **8 findings: 3 moderate, 3 high, 2 critical** (exit 1). Production-only audit still reports **zero** (exit 0). Counts are affected npm package chains, not independent exploit demonstrations; aggregate parents overlap their vulnerable transitive dependency. No fabricated all-clear is claimed.

Pending toolchain remediation, use only reviewed/trusted checkouts and isolated test runners without production secrets, artifact publishing or production connectivity; do not expose test/watch/MCP servers. The existing PR workflow has read-only repository permissions and builds a disposable candidate. These controls do not neutralize a compromised dependency or malicious test. The critical toolchain decision remains explicit for independent source/merge review; no owner risk acceptance is inferred from permission to implement Shopify fixes.
