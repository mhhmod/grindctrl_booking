Phase zero item 3, the App Proxy rate limit key. The three App Proxy routes (config, try-on context and Store Chat's messenger identity) are now keyed in `lib/shopify/proxy-rate-limit.ts` by the shop Shopify signed plus the anonymous visitor id the storefront sends (`vid` from both try-on scripts, kept in localStorage as `gc_tryon_vid`; the chat loader's existing `sid`), with a ceiling per shop that changing ids cannot escape: 30 requests a minute per visitor, and per shop 3,000 a minute for the two read routes and 300 for try-on context, which costs product resolution and an entitlement read. A request without a valid signature keeps the old address key, and the config route now serves a shop's settings only to a signed request; an unsigned one gets the shared defaults. A script deployed before visitor ids existed sends none and is held to the shop ceiling alone.
